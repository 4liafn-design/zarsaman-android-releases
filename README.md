# زرسامان — انتشار نسخه‌های اندروید

این مخزن عمومی فقط برای توزیع نسخه‌های تأییدشدهٔ برنامهٔ اندروید زرسامان است.

فایل APK را فقط از بخش **Releases** همین مخزن دریافت کنید و پیش از نصب، SHA-256 آن را با فایل checksum همان انتشار تطبیق دهید. اگر انتشار تأییدشده‌ای موجود نیست، فایل قابل دانلودی ارائه نشده است.

نسخه‌های دارای برچسب **Pre-release** آزمایشی هستند؛ محدودیت‌ها و نیازمندی‌های هر نسخه در توضیحات همان انتشار درج می‌شود.

- وب‌سایت: https://zarsaman.ir/
- حریم خصوصی: https://zarsaman.ir/privacy-policy/
- شرایط استفاده: https://zarsaman.ir/terms-of-service/
- راهنمای انتشار: [RELEASING.md](RELEASING.md)

## Distribution only

This repository contains release documentation and approved Android release assets only. Application source, backend files, credentials, private QA reports and user data must never be uploaded here.

A repository being public does not mean an APK has passed acceptance or is approved for publication. Release assets are published only after the applicable acceptance and authorization requirements are met.
